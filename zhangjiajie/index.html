武陵源军地坪 · 东门默认 · 10/4 晚机飞沪

⛰️ 张家界段

10/1 晚抵 → 10/2–10/3 核心峰林 → 10/4 半日赶机。票务走「张家界一机游」。

🏨 住军地坪 · 景区口原则

  • 优先武陵源军地坪 · 东门（吴家峪/标志门）步行圈，便于 7:00 前入园、10/4 快速取行李赶机
  • 不要住永定区（市区）：每天往返核心景区浪费 1–1.5h+
  • 主推 A：全季酒店(武陵源标志门店) · 评分 4.8 · 步行约 9 min 到东门环保车
  • 主推 B：瑞景缦山温德姆 · 评分 4.7 · 更舒适，到东门略远
  • 确认酒店 延迟退房 / 行李寄存（10/4 赶晚机刚需）

🎫 门票与预约

一机游
  • 官方渠道：微信小程序 「张家界一机游」
  • 推荐票：景车联票（大门票+环保车），约 236 元，连续 4 日（以支付页为准）
  • 索道 / 百龙天梯 / 小火车 另付；可预购
  • 预约：实名 + 分时段 + 指定门票站；国庆建议提前 3–7 天
  • 4 日内再入常需 再次预约当日时段（购票成功≠占满后续所有天）
  • 住军地坪 → 默认预约东门·吴家峪（标志门）

咨询电话（官方站公示）：门票 0744-5718833；游客服务 0744-5712345

📅 段内四日速览

完整时刻表见「行程」页 D2–D5；此处是执行要点

10/1 晚抵

不开园
  • 长沙南 → 张家界西（高铁优先）→ 军地坪入住
  • 简餐 + 备雨具/防滑鞋/充电宝
  • 核对次日东门预约；闹钟保证 06:40 前到吴家峪
  • 当晚红线：不进园、不上索道、不排天门山

10/2 山顶主线

必做
  • 东门 → 百龙天梯上 → 袁家界 → 天子山 → 索道下 → 十里画廊可选
  • 砍项：杨家界 → 十里画廊 → 天梯改索道上 → 只保两山顶

10/3 峡谷慢线

轻松
  • 金鞭溪（中段即可）→ 午休 → 下午补漏可砍
  • 天门山 / 玻璃桥默认不排

10/4 赶机

硬截止
  • 12:00 退房倾向并寄存行李
  • 18:15–18:30 前离开酒店上车
  • 20:00 前到荷花机场
  • 约 22:00+ 飞上海（以航司为准）
  • 红线：16:30 仍在山顶排队 → 立刻出园

🧭 高德基线（节日 ×1.5–2）

高德
  • 全季 → 吴家峪乘车处（步行）：469 m / ~9 min
  • 张家界西站 → 全季（驾车）：约 27 km / ~31 min → 国庆 50–70 min
  • 全季 / 温德姆 → 荷花机场：约 35 km / ~47 min → 国庆 75–100 min
  • 全季 → 南门售票处：约 25 km / ~42 min（非默认）

⚠️ 武陵源避雷

国庆
  • 黄牛票 / 非官方高价套票 — 只走官方小程序
  • 住市区每天通勤
  • 10/2 晚于 9:00 才第一次上百龙天梯
  • 把天门山塞进武陵源 3 天
  • 强制消费表演 / 拦车拉客 — 认准环保车体系
  • 雨天硬排山顶全线 — 可改金鞭溪
  • 10/4 赌机场大巴末班
  • 预约门站与实际到达门不一致
  • 只买大门票不买环保车
  • 轻信「必须坐天梯才算来过」— 队长可跳过

🍊 长沙星城游

2026.9.29 — 10.4 · 杭州东 → 长沙南 · 保利橘洲诺雅 → 北辰洲际 → 武陵源军地坪

旅行提示：长沙湘菜较辣，开口说「冒辣」。橘子洲坐观光车；岳麓优先书院，不硬爬山。武陵源国庆排队长，早进东门、环保车优先；10/4 18:15 前上车赶机。
