## 3. 交通耗时（高德驾车为主；节日建议在常态上 +30%）

| 路段 | 常态（高德） | **节日建议预留** | 备注 |
|------|--------------|------------------|------|
| **长沙南 → 诺雅** | ≈20.5 km / **≈31 min**（1835 s） | **45–60 min** | 夜抵优先打车；勿地铁拖行李折腾 |
| **长沙站 → 诺雅** | ≈14.3 km / **≈23 min** | **35–45 min** | 仅当车次到长沙站 |
| **诺雅 → 橘子洲头** | ≈6.4 km / **≈22 min** | **35–45 min** | 步行约 5.1 km / 68 min，**不推荐**；可用地铁 2 号线湘江中路 ↔ 橘子洲·青莲 |
| **橘子洲头 → 岳麓书院** | ≈6.4 km / **≈20 min** | **40–50 min** | 河西拥堵常见 |
| **岳麓书院 → 北辰洲际** | ≈9.6 km / **≈24 min** | **40–55 min** | |
| **诺雅 → 北辰洲际**（直接换宿） | ≈8.9 km / **≈24 min** | **40–50 min** | 行李一车搞定 |
| **北辰洲际 → 省博** | ≈5.6 km / **≈19 min** | **30–40 min** | 公交地铁约 45 min+步行 1.7 km，**打车更省心** |
| **北辰洲际 → 长沙南** | ≈21.7 km / **≈40 min** | **60–90 min** | 去张家界主出口 |
| **北辰洲际 → 长沙站** | ≈9.5 km / **≈25 min** | **40–50 min** | 仅备用 |

### 长沙 → 张家界（离开长沙）

- **优先：长沙南 → 张家界西** 高铁/动车。  
- 常识：日班次较多；最快约 **1.5–2 h** 量级，多数约 **2.5–3.5 h**（第三方时刻表汇总，**以 12306 为准**）。  
- 国庆晚班亦可能有车，但余票紧——**尽早锁票**；若只剩早/午班，需压缩省博时长。  
- 预留：**洲际退房 + 打车 60–90 min + 进站安检**。  
- 本调研**不规划**张家界玩法。

### 杭州 → 长沙（抵达常识）

- 杭州东 → 长沙南常见历时约 **4–5 h**。  
- 「约 22:30 到站」与晚间多趟 G 字头到站窗口吻合（示例见时刻表）；**订票以 12306 为准**。

## 4. 必做 / 可跳过 / 避雷

### 必做

1. **橘子洲头雕塑打卡**：坐观光车/小火车，2h 封顶。  
2. **岳麓「有文化感」的一版**：至少完成 **岳麓书院平路**（或雨天改为只书院/砍登山）。  
3. **湖南博物院（马王堆）**：10/1 主线，预约+证件。  
4. **两晚舒适住宿**：诺雅夜抵 + 洲际省博/离长。

### 可跳过

- 岳麓**登顶 / 爱晚亭硬排 / 索道长队**（体力或雨天直接砍）  
- IFS、坡子街、太平老街、文和友长队、天心阁  
- 橘子洲沙滩乐园 / 恐龙园等次要点  
- 烈士公园（10/1 下雨可砍）

### 避雷

| 项 | 说明 |
|----|------|
| **订错酒店** | 「诺亚方舟」≠「橘洲诺雅」 |
| **橘子洲走穿** | 本地共识踩雷；国庆更累 |
| **未预约入园** | 岳麓山·橘子洲国庆常见「非预约不入园」（近年政策；离园前用公众号复核） |
| **黄牛票** | 可能无法入园 |
| **索道雨停** | 9/30 小雨预报 |
| **坡子街整条** | 旧攻略红线，长沙段仍适用 |
| **地铁 15–17 点大客流** | 橘洲线可能临时跳站/空车（历史节假日措施） |
| **城内拉练** | 一天橘洲+岳麓已满，勿再加五一逛街 |
