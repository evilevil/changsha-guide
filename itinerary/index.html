诺雅 → 洲际 → 军地坪 · 节日 +30

🗺️ 全程行程 D0–D5

9/29 夜抵 · 9/30 橘洲+书院 · 10/1 省博赴张 · 10/2–10/3 峰林 · 10/4 赶机飞沪

🏨 长沙两晚换宿 · 武陵源军地坪

  • D0：长沙保利橘洲诺雅酒店（ORYARD）· 书院路 9 号保利国际广场 · 勿订开福「诺亚方舟」
  • D1 晚：长沙北辰洲际 · 湘江北路三段 1500 号 · 贴近省博 / 离长南站
  • D2–D5：武陵源军地坪（全季标志门 / 温德姆）· 步行圈进东门；10/4 晚机飞上海

💝 按她的喜好改过的版本

数据来源：微博 ups_and_downs_tz（浙江）原创帖 + 既有国庆偏好分析。不猜心思，只对齐可观察偏好。

  • 她要的：睡够、住得舒服、城内别拉练、有人把攻略扛完；长沙后接武陵源峰林
  • 她怕的：十一人挤人、堵车、连轴爬山、「来都来了」景点清单、自己从一堆攻略里做选择
  • 因此本版：长沙 唯一满日程日 = 9/30 橘洲+岳麓（强制观光车 + 书院默认 + 登山可砍）；其余日一天至多一个硬点；坡子街不进；累了回酒店算胜利

武陵源细则见张家界专页；微博锚点见微博本地手册。

📡 微博本地信号已写进每日行程

爬取 3060 帖（工作生活/打工人美食/避雷/博物馆等）→ 抽出与她「慢、少排队、文化+吃」重合的细则。完整摘录见「微博手册」；每日卡片里的「微博札记」是可执行版。张家界段以官方「一机游」+ 高德为准。

D0

9/29（周二）夜抵长沙南 · 入住保利橘洲诺雅

抵达日 | 不夜游

杭州东晚班 → 约 22:30 长沙南 → 打车住 保利橘洲诺雅（ORYARD） 1 晚。当晚只入住洗漱，不安排夜游。

⏰ 详细时间表

  • 出发前确认车次到站：长沙南（多数晚到 G 字头）或极少数长沙站；以 12306 为准
  • ≈22:30–23:00 出站（国庆人流 + 网约车排队缓冲）
  • ≈23:00–23:45 打车 → 保利橘洲诺雅（南站常态约 31 min → 节日 45–60 min）
  • ≈23:45–00:15 入住、洗漱；提前告知酒店晚到；问清车库/大堂电梯（保利综合体易迷路）
  • 当晚可做：微信预约 9/30 橘子洲 + 岳麓山/书院（公众号「岳麓山 橘子洲旅游区」，提前约 3 天；以当年公告为准）；若未约则锁 10/1 省博

📷 打卡机位

  • 诺雅大堂 / 江景房：夜抵合影即可，不专程夜游

📓 微博札记 · D0

  • 夜抵节奏：出站 → 打车 → 睡觉；首日别冲五一/文和友
  • 订房关键词用「保利橘洲诺雅 / ORYARD」，地址含 书院路 9 号 / 保利国际广场

订房避雷

  • 诺雅 ≠ 诺亚方舟：开福华夏路「长沙诺亚方舟大酒店」区位完全不同，勿订错
  • 备选同区位：全季长沙岳麓山橘子洲江景酒店（河西，近橘洲）
  • 点菜说「冒辣」：长沙默认辣度对杭州胃往往偏重（明日起适用）
D1

9/30（周三）橘子洲 + 岳麓书院 · 傍晚换北辰洲际

长沙唯一满日程日
撤退口令：人太多 / 晒不动 / 腿酸 / 索道停运 → 砍登山只留书院，或直接打车换洲际。

从诺雅近打橘洲（观光车封顶 2–2.5h）→ 下午岳麓 书院默认 → 傍晚换宿洲际。预报小雨：备伞；索道可能停。

⏰ 详细时间表

  • 07:30–08:30 起床早餐（雨天可稍晚）；确认景区预约码；「龙骧橘子洲」小程序预购观光车
  • 08:30–09:15 诺雅 → 橘子洲（打车/地铁湘江中路↔橘子洲·青莲；常态 ~22 min → 节日 35–45 min）
  • 09:15–11:30 必做橘子洲：进园 → 坐观光车/小火车到雕塑 → 江边短停 → 原路撤；全岛徒步禁止
  • 11:30–12:30 出洲午餐（河西简餐 / 回城粉面；不进坡子街）
  • 12:30–13:30 橘子洲 → 岳麓书院 / 东门（常态 ~20 min → 节日 40–50 min）
  • 13:30–16:00 岳麓体力友好三选一：A 书院平路 1–1.5h（默认）｜B 天晴索道上行短停｜C 门口拍照即走 / 砍岳麓
  • 16:00–17:00 回诺雅取行李（若未寄存）或行李直送会合
  • 17:00–18:00 打车 → 北辰洲际（诺雅→洲际常态 ~24 min → 节日 40–50 min）
  • 18:00–19:00 洲际入住；楼下茶颜 / 八一桥粉 / 酒店餐厅
  • 今晚：再确认 10/1 省博预约 + 长沙南→张家界西晚班高铁（以 12306 为准）

📷 打卡机位

  • 雕塑正面偏右 45°：上午 9–11 点光线最好
  • 雕塑侧面 + 江面：竖构图
  • 岳麓书院「惟楚有材」门联：正面站位，避开头顶过曝
  • 爱晚亭：人多就拍亭檐细节（非必做）

📓 微博札记 · D1

  • 踩雷共识：「橘子洲必须坐小火车！走路会累到怀疑人生」
  • 岳麓：国庆人海帖极多；本版 书院默认必做感，登山/索道标条件允许
  • 雨天索道可能停运；关园/停运就改书院或回城换宿

岳麓三选一

  • A 书院优先（默认）：只逛平路；不登山、不排索道 — 小雨/橘洲已累时选这个
  • B 索道上行+短走：仅天晴、体力尚可；现场购票，雨停风险高
  • C 砍岳麓：书院门口拍照或直接回城换宿
D2

10/1（周四）湖南博物院 · 晚高铁赴张家界西

省博主线 | 离长日

从洲际打车省博（马王堆为主）；预报中雨 → 室内主线更稳。傍晚退房 → 长沙南 → 张家界西 → 军地坪入住（当晚不开园）。

⏰ 详细时间表

  • 按预约时段 🏛️ 湖南博物院（东风路 50 号 / 高德名湖南省博物馆）；马王堆为主，不刷完
  • 馆后可跳过：烈士公园慢走（雨大则砍）；IFS
  • 午饭：甘长顺 / 杨裕兴 / 酒店周边；开口 冒辣
  • 下午：回洲际收拾；预留空档睡觉 / 滨江室内馆；建议提前 90–120 min 到长沙南（国庆安检）
  • 洲际 → 长沙南：常态约 40 min → 节日 60–90 min
  • 晚上：高铁 长沙南 → 张家界西（优先；约 1.5–3.5 h 量级，以 12306 为准）
  • 抵西站后打车/专线 → 武陵源军地坪酒店（西站→全季常态约 27 km / 31 min → 国庆 50–70 min）
  • 到店：简餐 + 核对次日「张家界一机游」东门吴家峪预约；不开园、不上索道；早睡

📷 打卡机位

  • 省博外观大台阶：正面全景
  • 马王堆展厅：禁止闪光；拍展板/空间即可

📓 微博札记 · D2

  • 高频结构：省博 → 烈士公园；雨天砍公园保馆
  • 粉面：别在太平街/坡子街/五一主街吃粉
  • 辣度：开口必须 冒辣

预约 & 离长

  • 微信/支付宝「湖南省博物馆」，约提前 5 天、约 20:00 放票；带证件原件
  • 国庆馆方常延长开放（高德曾写至约 20:00、最晚入馆约 19:00）——以馆方为准
  • 张家界西票尽早锁；只剩早/午班则压缩省博时长
D3

10/2（周五）武陵源 · 袁家界 + 天子山（东门 B 线）

核心必做

住军地坪 → 默认东门吴家峪。早入园百龙天梯上 → 袁家界 → 天子山 → 索道下 → 十里画廊可选。

⏰ 详细时间表

  • 闹钟 05:45–06:15，目标 06:40–07:00 到东门
  • 06:40–07:15 东门检票入园，乘环保车（联票含环保车）
  • 07:15–08:30 百龙天梯上行（赶旅行团前；队 >45 min 改天子山索道上）
  • 08:30–11:00 袁家界（必做）：观景台、迷魂台、乾坤柱/阿凡达取景、天下第一桥
  • 11:00–12:30 杨家界 / 空中田园 — 可跳过（人多先砍）
  • 12:30–14:30 天子山（必做）：御笔峰、仙女散花等
  • 14:30–16:00 天子山索道下山（建议作下山工具）
  • 16:00–17:30 十里画廊（体力好必做；累则跳过直接出园）

砍项口令（国庆）

  • 砍项顺序：① 杨家界 → ② 十里画廊 → ③ 天梯队过长改索道上 + 百龙下山 → ④ 只保「袁家界 + 天子山」
  • 票种建议：景车全价联票（含环保车），约 236 元/人、连续 4 日（以「一机游」支付页为准）；索道/天梯另付
  • 天门山 / 大峡谷玻璃桥：默认不排
D4

10/3（周六）金鞭溪慢线 · 补漏

轻松 / 可砍

峡谷徒步为主；下午可选补山顶漏点。天门山默认不排。

⏰ 详细时间表

  • 07:30–08:30 东门入园（可稍晚于昨日，仍建议 9:00 前）
  • 08:30–12:00 金鞭溪（必做峡谷线；中段即可，不必走穿）
  • 12:00–14:00 出园午饭 / 回酒店休整
  • 14:00–17:00 补：十里画廊 或 天子山/袁家界漏点 — 可跳过
  • 若 10/2 山顶严重失败：整日重做山顶环线，金鞭溪挪到 10/4 上午轻走 1–2h

大门认知

  • 武陵源核心景区与张家界国家森林公园是 同一张大门票体系；南门只是森林公园门票站，不是另一景区
  • 住军地坪 → 不要默认预约南门（除非专项走金鞭溪南段）
D5

10/4（周日）半日轻量 · 赶上海晚机

赶机日
赶机红线：16:30 仍在山顶排队索道 → 立刻放弃景点，直奔出园赶机。

12:00 倾向退房寄存；18:15 前离开酒店上车；20:00 前到荷花机场；约 22:00+ 飞上海（以航司为准）。

⏰ 详细时间表

  • 方案 A（推荐）：不进园或仅东门周边走走；上午退房寄存；休整打包
  • 方案 B：07:00–12:00 轻走十里画廊或金鞭溪短段；12:30 前出园
  • 禁止：再排百龙天梯 / 天子山索道上行
  • 12:00 建议退房（或协议延迟至 14:00）+ 行李寄存
  • 17:30–18:00 取行李 / 结尾款
  • 18:15–18:30 打车赴荷花机场（军地坪约 35 km / 畅通 ~47 min → 国庆预留 75–100 min）
  • 20:00 前到航站楼值机安检（国内常见起飞前约 40 min 停办值机，以当日航司为准）
  • 22:00+ 起飞赴上海

机场缓冲

  • 赶 22:00+ 航班 优先打车，勿赌机场大巴末班
  • 航班缓冲优先于景点完整度；具体航班号锁定后再微调倒推表
